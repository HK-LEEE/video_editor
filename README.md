# voxshift

내 목소리를 녹음해서 바로 변조하는 보이스 체인저입니다. 학습이나 GPU 없이 맥에서 돌아갑니다.

WORLD 보코더(pyworld)로 목소리를 피치와 포먼트(음색)로 나눠 따로 움직이고, pedalboard 효과를 얹습니다.
피치만 바꾸는 일반 피치시프트보다 덜 "다람쥐"처럼 들립니다.

## 설치 (맥)

```bash
brew install ffmpeg
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 웹 화면

```bash
python app.py
```

브라우저에서 http://127.0.0.1:7860 을 열고

1. 마이크 버튼으로 녹음하거나 m4a/wav 파일을 올립니다 (처음엔 브라우저가 마이크 권한을 물어봅니다)
2. 목소리를 고르고 **변조하기**를 누르면 결과를 바로 듣고 내려받을 수 있습니다
3. **모든 프리셋 한 번에 비교**를 열면 8가지 결과를 나란히 들어볼 수 있습니다
4. **강도** 슬라이더로 프리셋의 피치·포먼트 변화를 최대 3배까지 키울 수 있습니다
5. **직접 조절**을 고르면 피치(±24반음)·포먼트(0.5~2.0) 슬라이더를 마음대로 움직일 수 있습니다

## 더빙 스튜디오 (영상에 내 목소리 입히기)

`python app.py` 실행 후 http://127.0.0.1:7860/studio

1. 영상(mp4, mov, webm)을 끌어 놓습니다
2. 원하는 위치에서 **⏺ 여기서 녹음**(`R`)을 누르면 영상이 재생되면서 녹음되고, 멈추면 그 위치에 구간으로 들어갑니다
3. 타임라인에서 구간을 끌어 옮기고, 양 끝을 끌어 다듬고, 재생 위치에서 `S`로 자릅니다. `Delete`로 지웁니다
4. 구간을 눌러 목소리·강도·볼륨을 구간마다 따로 정합니다. 재생하면 변조된 소리로 미리 들을 수 있습니다
5. **영상으로 내보내기**를 누르면 변조된 목소리를 입힌 mp4가 만들어집니다 (원본 소리 슬라이더로 원래 소리를 섞을 수 있습니다)

- 스피커로 원본 소리를 들으며 녹음하면 녹음에 섞이니, 원본을 들으려면 헤드폰을 쓰세요
- 녹음이 영상보다 늦게 들리면 **싱크 보정**(ms)을 키웁니다
- 작업은 브라우저에 자동 저장되어 새로고침해도 이어집니다. 영상·녹음·결과 파일은 `workspace/` 폴더에 쌓입니다

## 명령줄

```bash
python -m voxshift --list                       # 프리셋 목록
python -m voxshift 녹음.m4a --preset deep        # 프리셋 하나
python -m voxshift 녹음.m4a --preset all         # 전부 만들어 output/에 저장
python -m voxshift 녹음.m4a --pitch 5 --formant 1.15
python -m voxshift 녹음.m4a --preset giant --intensity 1.5
```
