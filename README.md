# video_editor

내 목소리를 녹음해서 바로 변조하는 보이스 체인저입니다. 학습이나 GPU 없이 맥에서 돌아갑니다.

WORLD 보코더(pyworld)로 목소리를 피치와 포먼트(음색)로 나눠 따로 움직이고, pedalboard 효과를 얹습니다.
피치만 바꾸는 일반 피치시프트보다 덜 "다람쥐"처럼 들립니다.

## 설치 (맥)

```bash
brew install ffmpeg
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 웹 화면

```bash
python app.py
```

브라우저에서 http://127.0.0.1:7860 을 열고

1. 마이크 버튼으로 녹음하거나 m4a/wav 파일을 올립니다 (처음엔 브라우저가 마이크 권한을 물어봅니다)
2. 목소리를 고르고 **변조하기**를 누르면 결과를 바로 듣고 내려받을 수 있습니다
3. **모든 프리셋 한 번에 비교**를 열면 8가지 결과를 나란히 들어볼 수 있습니다
4. **강도** 슬라이더로 프리셋의 피치·포먼트 변화를 최대 3배까지 키울 수 있습니다
5. **직접 조절**을 고르면 피치(±24반음)·포먼트(0.5~2.0) 슬라이더를 마음대로 움직일 수 있습니다

## 영상 편집기 (멀티트랙)

`python app.py` 실행 후 http://127.0.0.1:7860/editor (예전 `/studio` 주소는 여기로 연결됩니다)

- **보관함**: 영상·음악·효과음 파일을 올려 두고 타임라인으로 끌어 놓습니다 (두 번 누르면 재생 위치에 들어갑니다). 소리가 있는 영상은 영상 클립과 오디오 클립이 **연결**된 채 들어가고, 함께 움직이고 잘립니다 (`⌥ Option`을 누르고 끌면 연결을 무시합니다)
- **트랙**: 영상 트랙과 오디오 트랙을 원하는 만큼 추가합니다. 위 영상 트랙이 아래를 가립니다. 오디오 트랙은 모두 섞이고, 트랙마다 음소거(M)·솔로(S)·볼륨·녹음 대상(⏺)이 있습니다
- **녹음**: 녹음 대상 트랙에 재생 위치부터 녹음하고(`R`), 클립으로 들어갑니다. 구간마다 목소리 프리셋·강도·볼륨을 속성 패널에서 고릅니다
- **편집**: 끌어 옮기기(트랙 사이 포함), 양 끝으로 다듬기, `S` 자르기, `Delete` 지우기, `⌘Z` 실행 취소, 자석(클립 끝·재생 위치에 붙이기)
- **영상에 녹이기** (트랙 속성): 공간감(리버브), 보이스가 나올 때 줄이기(덕킹), 크기 고르게, 말 사이 잡음 줄이기, 톤 다듬기. 보이스 트랙으로 지정한 트랙이 나올 때 다른 트랙이 줄어듭니다
- 미리듣기는 서버가 내보내기와 똑같이 섞은 소리를 재생하므로 결과가 같습니다. **내보내기**는 모든 영상 트랙을 합치고(빈 곳은 검은 화면) 오디오 믹스를 입힌 mp4를 만듭니다
- 키보드: `Space` 재생, `←`/`→` 0.1초 (`Shift` 1초), `,`/`.` 한 프레임, `[`/`]` 이전/다음 경계, `Home`/`End`, `⌥`+`←`/`→` 선택 클립 미세 이동
- 헤드폰 없이 스피커로 원본 소리를 들으며 녹음하면 녹음에 섞입니다. 녹음이 늦게 들리면 **싱크 보정**(ms)을 키웁니다
- 작업(타임라인)은 브라우저에 저장되어 새로고침해도 이어집니다. 파일은 `workspace/projects/<프로젝트>/`에 프로젝트별로 쌓입니다 (아래 '프로젝트' 참고)

### 전환 효과 · PiP · 자막

- **전환 효과**: 영상 클립을 고르면 속성 패널의 **전환 효과**에서 페이드·검정을 거쳐서·와이프(좌/우)·밀기(좌/우)와 길이(0.1~3초)를 고릅니다. 클립이 *시작할 때* 아래 화면에서 이 클립으로 넘어갑니다. 앞 클립에 바로 이어 붙이면 앞 클립 끝이 자동으로 겹쳐져 두 화면이 섞이고(영상이 모자라면 마지막 장면을 붙잡음), 첫 클립은 검은 화면에서 나타납니다. 전환이 걸린 구간은 타임라인에 흰 삼각형으로 보입니다
- **PiP (화면 속 화면)**: 영상 클립의 **배치**를 *작은 화면(PiP)*으로 바꾸면 아래 영상을 가리지 않고 위에 작게 겹칩니다. 크기·위치·불투명도·테두리를 조절하고, **미리보기 화면에서 끌어서** 옮길 수도 있습니다. PiP는 트랙 순서와 상관없이 항상 큰 화면 위에 올라갑니다. 출력 화면 크기는 PiP가 아닌 첫 클립을 따릅니다
- **자막 트랙**: 타임라인 맨 위의 `자막` 줄. `T` 키나 `＋`로 재생 위치에 자막을 넣고, 끌어서 옮기고 양 끝으로 길이를 조절하며, 속성 패널에서 내용·시작/끝·언어를 고칩니다 (`S`로 자르기, `Delete`로 지우기). **자막 스타일**(글꼴·크기·색·외곽선·배경 상자·세로 위치, 프리셋 3종)은 모든 자막에 같이 적용됩니다. 크기와 위치는 화면 비율이라 세로 영상에도 그대로 맞습니다
- **내보내기**: mp4에 자막을 입히고(libass), **SRT 파일로 내보내기**도 됩니다. 글꼴은 맥에 설치된 글꼴 이름(기본 `Apple SD Gothic Neo`)을 쓰고, 내보낸 영상의 글자 크기는 글꼴에 따라 미리보기와 몇 % 다를 수 있습니다
- 자막 한 줄(Cue)에는 `lang`(언어)과 `source`(manual / ai / translation)가 있어서, 이후 AI 받아쓰기·번역 자막을 같은 트랙에 채우고 `subtitle_lang`으로 입힐 언어를 고르게 만들 수 있습니다

### 속도 · 볼륨 키프레임 · 색 보정

- **속도**: 클립을 고르면 속성 패널의 **속도**(0.25~4배, 슬라이더 또는 0.5×·2× 버튼)로 빠르게/느리게 합니다. **소리 높이는 그대로** 유지됩니다(Rubber Band 시간 늘이기). 타임라인에서 클립 길이는 `원본 구간 ÷ 속도`가 되고 `⏩2×` 표시가 붙습니다. 영상+소리 연결 클립은 같이 바뀌고, 뒤 클립을 자동으로 밀지는 않습니다
- **볼륨 키프레임**: 오디오 클립을 고른 뒤 타임라인에서 **두 번 누르면 점**이 생기고(가운데 줄 = 100%), 끌어서 옮기고, 점을 두 번 누르면 지웁니다. 속성 패널에서 시간(초)·볼륨(%)을 숫자로 고칠 수도 있고 `재생 위치에 점`으로도 추가합니다. 점 사이는 직선으로 변해서 페이드 인/아웃이나 말할 때만 음악 줄이기에 씁니다. 트랙을 고르면 **트랙 전체 볼륨 자동화**(타임라인 기준)도 같은 방법으로 됩니다. 클립을 자르면 점이 자른 자리에서 나뉩니다
- **색 보정**: 영상 클립의 **밝기·대비·채도·색온도**와 프리셋(선명·따뜻·차갑게·시네마·빈티지·흑백), `모든 영상 클립에 적용`. 미리보기(SVG 필터)와 내보내기(ffmpeg `eq`·`colorchannelmixer`)가 같은 식이라 거의 같은 색입니다
- 속도와 볼륨 키프레임은 소리 미리듣기·내보내기 둘 다 같은 `render_audio`로 반영되고, 색 보정은 소리 믹스 캐시에 영향을 주지 않습니다

### 쇼츠 · 릴스 미리보기 (📱 쇼츠/릴스 버튼)
- 9:16 세로 화면 위에 YouTube 쇼츠 / Instagram 릴스 앱 화면(버튼·계정·캡션 자리)을 직접 만든 목업으로 겹쳐 보여주고, 앱에 **가려지는 영역은 빗금**으로 표시해요.
- 그 화면 안에서 **꽉 채우기(자르기)**: 끌어서 위치, 휠로 확대 / **전체 보이게**: 위아래를 흐린 배경으로 채움. **길이 줄이기**: 시작·끝 지정, 포맷 제한(쇼츠 180초, 릴스 90초)에 맞추기.
- 포맷마다 설정을 따로 저장하고, 각각 **1080×1920 mp4**로 내보내요 (`POST /api/export/short`). 자막은 안전 영역 안으로 옮겨서 입혀요.
- 제한 길이·안전 영역 숫자는 `video_editor/shorts.py`의 `FORMATS`에서 바꿔요 (앱 업데이트에 따라 달라질 수 있는 대략적인 값).

## AI 음성 변환 (Seed-VC)

내 녹음을 원하는 사람(샘플 목소리)의 음색으로 바꿉니다. 샘플은 약 10초의 깨끗한 말소리(m4a/wav)면 됩니다.

```bash
bash scripts/setup_ai_voice.sh   # 한 번만: PyTorch + Seed-VC 설치 (별도 가상환경 .venv-seedvc)
python app.py
```

1. 보관함에 샘플 목소리 파일을 올립니다
2. 오디오 클립을 고르고 속성 패널의 **목소리**에서 `AI · (샘플 이름)`을 고릅니다
3. **🤖 AI 변환 만들기**를 누릅니다. 처음엔 모델(수 GB)을 내려받아 오래 걸리고, 이후엔 클립마다 한 번만 변환됩니다 (맥은 MPS 가속)
4. 변환 전에는 원본이 들리고, 변환 안 된 클립이 있으면 내보내기가 막힙니다

## AI 편집 도구 (🤖 AI 도구 버튼)

편집기 상단의 **🤖 AI 도구**에서 여섯 가지를 씁니다. 타임라인에서 클립을 고르고 누르세요 (고른 클립이 없으면 재생 위치 아래 클립).

| 기능 | 하는 일 | 필요한 것 |
|---|---|---|
| 1. 자동 자막 | 말을 받아 적어 자막 트랙에 넣음 (한국어 포함, `lang`/`source=ai`) | `setup_ai_tools.sh` |
| 2. 무음·군말 자르기 | 조용한 구간과 "어, 음"을 찾아 보여 주고, 잘라낸 뒤 빈틈을 붙임 (자막도 같이 당김, ⌘Z로 한 번에 취소) | 무음은 없음 / 군말은 `setup_ai_tools.sh` |
| 3. 장면 나누기 | 화면이 바뀌는 곳마다 영상(과 연결된 소리)을 자름 | 없음 (ffmpeg) |
| 4. 노이즈 제거 | 배경 잡음을 줄인 소리로 클립을 바꿈 (원본은 보관함에 남음) | RNNoise 모델은 설치 스크립트가 받음, 없으면 FFT 방식 |
| 5. 대본 읽기 | 글을 음성으로 읽어 재생 위치에 넣음 | 맥 내장 `say`(한국어 Yuna), 리눅스는 espeak-ng |
| 6. 번역 더빙 | 자막을 번역(`source=translation`)하고, 번역문을 읽은 음성을 자막 시각에 맞춰 넣음 | `setup_ai_tools.sh` + 읽기 엔진 |

```bash
bash scripts/setup_ai_tools.sh   # 한 번만: faster-whisper·argos 번역(.venv-aitools)과 모델, RNNoise 모델을 내려받음
```

- 받아쓰기 모델은 기본 `large-v3-turbo`(약 1.6GB)이고 환경변수 `AITOOLS_WHISPER=large-v3`로 바꿀 수 있어요. 결과는 열린 프로젝트의 `cache`에 저장돼 같은 미디어는 두 번째부터 바로 나옵니다.
- 군말 찾기는 "음, 어"를 그대로 적도록 유도해서 받아쓰지만, Whisper가 일부 군말을 빼먹을 수 있어요. 분석 결과를 확인한 뒤 적용하세요.
- 번역은 영어를 거쳐 갑니다 (한국어→일본어 = 한→영→일). 번역하면 `영상에 입힐 자막 언어`가 번역 언어로 바뀝니다 (자막 속성 패널에서 되돌릴 수 있음).
- 더빙은 읽은 소리가 자막 시간보다 길면 최대 1.6배까지 빠르게 합니다. 원래 말소리는 트랙의 음소거로 끄세요.
- 맥 Apple Silicon에서는 받아쓰기가 CPU(int8)로 돌아요. 긴 영상은 몇 분 걸릴 수 있습니다.
- 서버 주소: `/api/ai/{tools,transcribe,cuts,scenes,denoise,tts,translate,dub}` (오래 걸리는 작업은 `/api/ai/jobs/{id}`로 결과를 받음, AI 음성 변환과 같은 한 번에 하나씩 작업 목록).

## 자동 이어 붙이기 (🎞 자동 이어붙이기 버튼)

AI로 만든 5~10초짜리 캐릭터 쇼츠 같은 짧은 영상 여러 개를 순서대로 이어 붙일 때 어색하지 않게 다듬어 줍니다. 오른쪽 `이어붙이기` 탭에서
**보관함에서 담기 / 파일 올려서 담기 / 타임라인의 영상 담기** → **분석하기** → 이음새마다 미리 보고 고치기 → **타임라인에 이어 붙이기** (⌘Z로 되돌리기).

| 하는 일 | 방법 |
|---|---|
| 앞뒤 불량 프레임 정리 | 영상을 32x18로 줄여 검은 화면·멈춘 화면(생성 영상 끝에 잘 붙음)·시작/끝의 깜빡이는 글리치를 찾아 잘라냄 (앞 1초·뒤 1.5초까지). 영상마다 시작·끝 초를 직접 고칠 수도 있고, 앞 영상 끝과 똑같이 시작하면 중복 첫 화면도 건너뜀 |
| 색·밝기 맞춤 | 뒤 영상의 시작 화면을 앞 영상의 끝(보정 뒤)에 맞춰 밝기·채도·색온도 보정을 클립 색 보정에 넣음. 아주 다른 장면이면 약하게만 |
| 소리 | 영상마다 소리 크기를 중간값에 맞추고(게인), 이음새에서 앞 소리를 조금 더 이어 붙여 크로스페이드 (소리는 두 트랙에 번갈아 놓임) |
| 전환 자동 선택 | 끝 화면·시작 화면의 모양/색 차이와 움직임으로: 거의 같거나 움직임이 이어지면 **하드컷** → 조금 다르면 **크로스 디졸브** → 꽤 다르면 **AI 모핑**(RIFE 설치 시, 아니면 디졸브) → 전혀 다른 장면이면 **암전**. 이음새마다 `▶ 미리보기`(앞뒤 1.6초를 실제 내보내기와 같은 방식으로 렌더)로 보고 방식·길이·색 맞춤·소리 섞기를 바꿀 수 있음 |
| 순서 제안 (선택) | `닮은 순서로 자동 제안`: 첫 영상은 두고 끝 화면이 가장 닮은 영상을 다음에 붙임 |
| AI 모핑 | 앞 영상 마지막 화면과 뒤 영상 첫 화면 사이를 RIFE(rife-ncnn-vulkan, 맥은 Metal)로 보간한 짧은 영상을 만들어 사이에 끼움. `bash scripts/setup_ai_morph.sh` 한 번 (설치 안 했으면 ffmpeg `minterpolate`로 대신) |

### Claude 연결 (문구 탭)
- **기본: Claude Code 헤드리스 모드.** 컴퓨터에 설치된 `claude` 명령(`claude -p`)을 내 Claude 로그인으로 불러 써서 **API 키가 필요 없어요.** 터미널에서 `claude`를 한 번 실행해 로그인해 두면 끝입니다. (`claude`가 없으면 `npm install -g @anthropic-ai/claude-code`)
- **대체: Claude API 키.** 문구 탭에서 방식을 'Claude API 키'로 바꾸고, `export ANTHROPIC_API_KEY=sk-ant-...` 후 `python app.py`를 실행하거나 키 칸에 붙여넣으세요(`workspace/settings.json`, git 제외, 권한 600). `claude`가 없고 키만 있으면 자동으로 API로 갑니다. **키는 저장소에 올라가지 않습니다.**

준비가 안 됐으면 문구 탭이 무엇을 하면 되는지 알려 줘요. 대본 글만 보내며 영상·소리는 보내지 않습니다.

새 API: `GET /api/library`, `POST /api/library/ensure|upload`, `POST /api/beats`, `POST /api/beats/plan`, `GET/PUT /api/settings`, `POST /api/ai/copy`, `POST /api/thumbnail`, `GET/POST/DELETE /api/templates`, `/api/endings`(+`/preview`, `/apply`), `POST /api/template/apply|batch`, `GET/POST/DELETE /api/projects`, `POST /api/batch/export`.

## 원하는 목소리로 읽기 (TTS) · 더빙 목소리

AI 도구 → **5. 대본 읽기**의 *읽을 목소리*에서 고릅니다.

- **기본 목소리**: 컴퓨터에 내장된 읽기 엔진 그대로.
- **📁 샘플 목소리**: 10~30초짜리 깨끗한 음성 파일을 올리면(📁 버튼) 학습 없이 그 목소리로 바뀝니다 (대본을 TTS로 읽은 뒤 Seed-VC로 음색 변환, 제로샷). 더빙 성우처럼 특정 목소리는 그 사람의 샘플만 올리면 됩니다.
- **🎭 보이스 캐릭터**: 샘플 + 프리셋 변조를 이름 붙여 저장해 둔 것. 읽기·번역 더빙·클립 어디서든 같은 목소리.
- ▶ **미리듣기**로 글 앞부분만 들어 보고 `읽어서 넣기`를 누릅니다. AI 음성 변환은 `bash scripts/setup_ai_voice.sh`로 설치해야 합니다.

더 똑같이 만들려는 *학습(파인튜닝)* 은 앱 안에서는 지원하지 않습니다 (몇 분 분량 학습이 필요하고 맥(MPS)에서는 느림). 필요하면 Seed-VC의 `train.py`로 따로 학습한 체크포인트를 `third_party/seed-vc`에 두는 방식으로 붙일 수 있습니다.

### 예전 작업 폴더에서 옮기기 (자동, 한 번)

프로젝트 구분이 없던 예전 구조(`workspace/media·cache·exports·projects/*.json`)로 쌓인 폴더에서 처음 켜면, 내용이 **'기존 작업'** 프로젝트로 옮겨져요.
파일은 같은 폴더 안에서 이름만 바꿔 옮기고(복사·삭제 없음), 같은 이름이 있으면 덮지 않고 `legacy-leftovers/`로 비켜 둬요.
옮기기 전 메타데이터(`media/*.json`, 보관본, 캐릭터·템플릿·설정) 백업과 파일 목록·옮긴 뒤 개수·크기 대조 기록이 `workspace/_migration/`에 남아요. 중간에 멈춰도 다시 켜면 이어서 끝나고, 이미 옮겼으면 아무것도 안 해요.
미디어 id와 보관한 프로젝트 JSON은 바뀌지 않아서 기존 편집 상태·보관본이 그대로 열려요 (브라우저에 저장돼 있던 예전 편집 상태는 '기존 작업'이 이어받아요).
