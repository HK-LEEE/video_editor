# video_editor

내 목소리를 녹음해서 바로 변조하는 보이스 체인저입니다. 학습이나 GPU 없이 맥에서 돌아갑니다.

WORLD 보코더(pyworld)로 목소리를 피치와 포먼트(음색)로 나눠 따로 움직이고, pedalboard 효과를 얹습니다.
피치만 바꾸는 일반 피치시프트보다 덜 "다람쥐"처럼 들립니다.

## 설치 (맥)

```bash
brew install ffmpeg
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 웹 화면

```bash
python app.py
```

브라우저에서 http://127.0.0.1:7860 을 열고

1. 마이크 버튼으로 녹음하거나 m4a/wav 파일을 올립니다 (처음엔 브라우저가 마이크 권한을 물어봅니다)
2. 목소리를 고르고 **변조하기**를 누르면 결과를 바로 듣고 내려받을 수 있습니다
3. **모든 프리셋 한 번에 비교**를 열면 8가지 결과를 나란히 들어볼 수 있습니다
4. **강도** 슬라이더로 프리셋의 피치·포먼트 변화를 최대 3배까지 키울 수 있습니다
5. **직접 조절**을 고르면 피치(±24반음)·포먼트(0.5~2.0) 슬라이더를 마음대로 움직일 수 있습니다

## 영상 편집기 (멀티트랙)

`python app.py` 실행 후 http://127.0.0.1:7860/editor (예전 `/studio` 주소는 여기로 연결됩니다)

- **보관함**: 영상·음악·효과음 파일을 올려 두고 타임라인으로 끌어 놓습니다 (두 번 누르면 재생 위치에 들어갑니다). 소리가 있는 영상은 영상 클립과 오디오 클립이 **연결**된 채 들어가고, 함께 움직이고 잘립니다 (`⌥ Option`을 누르고 끌면 연결을 무시합니다)
- **트랙**: 영상 트랙과 오디오 트랙을 원하는 만큼 추가합니다. 위 영상 트랙이 아래를 가립니다. 오디오 트랙은 모두 섞이고, 트랙마다 음소거(M)·솔로(S)·볼륨·녹음 대상(⏺)이 있습니다
- **녹음**: 녹음 대상 트랙에 재생 위치부터 녹음하고(`R`), 클립으로 들어갑니다. 구간마다 목소리 프리셋·강도·볼륨을 속성 패널에서 고릅니다
- **편집**: 끌어 옮기기(트랙 사이 포함), 양 끝으로 다듬기, `S` 자르기, `Delete` 지우기, `⌘Z` 실행 취소, 자석(클립 끝·재생 위치에 붙이기)
- **영상에 녹이기** (트랙 속성): 공간감(리버브), 보이스가 나올 때 줄이기(덕킹), 크기 고르게, 말 사이 잡음 줄이기, 톤 다듬기. 보이스 트랙으로 지정한 트랙이 나올 때 다른 트랙이 줄어듭니다
- 미리듣기는 서버가 내보내기와 똑같이 섞은 소리를 재생하므로 결과가 같습니다. **내보내기**는 모든 영상 트랙을 합치고(빈 곳은 검은 화면) 오디오 믹스를 입힌 mp4를 만듭니다
- 키보드: `Space` 재생, `←`/`→` 0.1초 (`Shift` 1초), `,`/`.` 한 프레임, `[`/`]` 이전/다음 경계, `Home`/`End`, `⌥`+`←`/`→` 선택 클립 미세 이동
- 헤드폰 없이 스피커로 원본 소리를 들으며 녹음하면 녹음에 섞입니다. 녹음이 늦게 들리면 **싱크 보정**(ms)을 키웁니다
- 작업(타임라인)은 브라우저에 저장되어 새로고침해도 이어집니다. 파일은 `workspace/`에 쌓입니다

### 전환 효과 · PiP · 자막

- **전환 효과**: 영상 클립을 고르면 속성 패널의 **전환 효과**에서 페이드·검정을 거쳐서·와이프(좌/우)·밀기(좌/우)와 길이(0.1~3초)를 고릅니다. 클립이 *시작할 때* 아래 화면에서 이 클립으로 넘어갑니다. 앞 클립에 바로 이어 붙이면 앞 클립 끝이 자동으로 겹쳐져 두 화면이 섞이고(영상이 모자라면 마지막 장면을 붙잡음), 첫 클립은 검은 화면에서 나타납니다. 전환이 걸린 구간은 타임라인에 흰 삼각형으로 보입니다
- **PiP (화면 속 화면)**: 영상 클립의 **배치**를 *작은 화면(PiP)*으로 바꾸면 아래 영상을 가리지 않고 위에 작게 겹칩니다. 크기·위치·불투명도·테두리를 조절하고, **미리보기 화면에서 끌어서** 옮길 수도 있습니다. PiP는 트랙 순서와 상관없이 항상 큰 화면 위에 올라갑니다. 출력 화면 크기는 PiP가 아닌 첫 클립을 따릅니다
- **자막 트랙**: 타임라인 맨 위의 `자막` 줄. `T` 키나 `＋`로 재생 위치에 자막을 넣고, 끌어서 옮기고 양 끝으로 길이를 조절하며, 속성 패널에서 내용·시작/끝·언어를 고칩니다 (`S`로 자르기, `Delete`로 지우기). **자막 스타일**(글꼴·크기·색·외곽선·배경 상자·세로 위치, 프리셋 3종)은 모든 자막에 같이 적용됩니다. 크기와 위치는 화면 비율이라 세로 영상에도 그대로 맞습니다
- **내보내기**: mp4에 자막을 입히고(libass), **SRT 파일로 내보내기**도 됩니다. 글꼴은 맥에 설치된 글꼴 이름(기본 `Apple SD Gothic Neo`)을 쓰고, 내보낸 영상의 글자 크기는 글꼴에 따라 미리보기와 몇 % 다를 수 있습니다
- 자막 한 줄(Cue)에는 `lang`(언어)과 `source`(manual / ai / translation)가 있어서, 이후 AI 받아쓰기·번역 자막을 같은 트랙에 채우고 `subtitle_lang`으로 입힐 언어를 고르게 만들 수 있습니다

### 속도 · 볼륨 키프레임 · 색 보정

- **속도**: 클립을 고르면 속성 패널의 **속도**(0.25~4배, 슬라이더 또는 0.5×·2× 버튼)로 빠르게/느리게 합니다. **소리 높이는 그대로** 유지됩니다(Rubber Band 시간 늘이기). 타임라인에서 클립 길이는 `원본 구간 ÷ 속도`가 되고 `⏩2×` 표시가 붙습니다. 영상+소리 연결 클립은 같이 바뀌고, 뒤 클립을 자동으로 밀지는 않습니다
- **볼륨 키프레임**: 오디오 클립을 고른 뒤 타임라인에서 **두 번 누르면 점**이 생기고(가운데 줄 = 100%), 끌어서 옮기고, 점을 두 번 누르면 지웁니다. 속성 패널에서 시간(초)·볼륨(%)을 숫자로 고칠 수도 있고 `재생 위치에 점`으로도 추가합니다. 점 사이는 직선으로 변해서 페이드 인/아웃이나 말할 때만 음악 줄이기에 씁니다. 트랙을 고르면 **트랙 전체 볼륨 자동화**(타임라인 기준)도 같은 방법으로 됩니다. 클립을 자르면 점이 자른 자리에서 나뉩니다
- **색 보정**: 영상 클립의 **밝기·대비·채도·색온도**와 프리셋(선명·따뜻·차갑게·시네마·빈티지·흑백), `모든 영상 클립에 적용`. 미리보기(SVG 필터)와 내보내기(ffmpeg `eq`·`colorchannelmixer`)가 같은 식이라 거의 같은 색입니다
- 속도와 볼륨 키프레임은 소리 미리듣기·내보내기 둘 다 같은 `render_audio`로 반영되고, 색 보정은 소리 믹스 캐시에 영향을 주지 않습니다

## AI 음성 변환 (Seed-VC)

내 녹음을 원하는 사람(샘플 목소리)의 음색으로 바꿉니다. 샘플은 약 10초의 깨끗한 말소리(m4a/wav)면 됩니다.

```bash
bash scripts/setup_ai_voice.sh   # 한 번만: PyTorch + Seed-VC 설치 (별도 가상환경 .venv-seedvc)
python app.py
```

1. 보관함에 샘플 목소리 파일을 올립니다
2. 오디오 클립을 고르고 속성 패널의 **목소리**에서 `AI · (샘플 이름)`을 고릅니다
3. **🤖 AI 변환 만들기**를 누릅니다. 처음엔 모델(수 GB)을 내려받아 오래 걸리고, 이후엔 클립마다 한 번만 변환됩니다 (맥은 MPS 가속)
4. 변환 전에는 원본이 들리고, 변환 안 된 클립이 있으면 내보내기가 막힙니다

## 구조

```
app.py                     Gradio(간단 변조기) + FastAPI(/editor, /api) 서버
video_editor/engine.py     피치·포먼트 변조 엔진(pyworld), 효과(pedalboard), 피크 리미터
video_editor/presets.yaml  목소리 프리셋 15종
video_editor/editor.py     보관함, 트랙 믹스·효과·덕킹, 영상 합치기(전환·PiP), API
video_editor/subtitles.py  자막 트랙 모델, SRT·ASS 만들기
video_editor/static/editor.html  편집기 화면 (프레임워크 없는 단일 파일)
tests/                     엔진·편집기 테스트
```

## 명령줄

```bash
python -m video_editor --list                       # 프리셋 목록
python -m video_editor 녹음.m4a --preset deep        # 프리셋 하나
python -m video_editor 녹음.m4a --preset all         # 전부 만들어 output/에 저장
python -m video_editor 녹음.m4a --pitch 5 --formant 1.15
python -m video_editor 녹음.m4a --preset giant --intensity 1.5
```
